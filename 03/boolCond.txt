1. xが12以上、かつ、xが34以下　　　　　　　　　　　　→　　1.x >= 12 && x <= 34
2. xが12以下、または、xが34以上                  →   2.x <= 12 || x >= 34
3. xが10より大きい、かつ、yが10より小さい          →   3.x > 10 && y < 10
4. xとyが共に負                                →   4.x < 0 && y < 0
5. xが3で割り切れ、5でも割り切れる                →   5.x % 3 == 0 && x % 5 == 0
6. xとyの少なくともどちらかは0                   →  6.x == 0 || y == 0
7. xは正の偶数                                 →   7.x > 0 && x % 2 == 0
8. xとyは共に正の数、または、xとyは共に負の数       →  8.(x > 0 && y > 0) || (x < 0 && y < 0)
